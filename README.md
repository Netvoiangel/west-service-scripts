# west-service-scripts

Набор сервисных скриптов для рабочих задач.

## Монтирование архивного диска HWMONITOR

Скрипт: `scripts/mount-hwmonitor-disk.ps1`

Сценарий рассчитан на Windows-устройство, с которого есть SSH-доступ на целевую машину:

```powershell
ssh root@192.168.1.1
```

Зависимости не нужны, используется только PowerShell и встроенный SSH-клиент Windows.

### Что делает скрипт

- подключается к устройству по SSH;
- читает список дисков через `lsblk`;
- определяет системный диск через корневую файловую систему `/`;
- читает `/opt/mnt2/configurator/conf/HWMONITOR.json`;
- сохраняет локальный бэкап конфига в `backups/`;
- ищет archive mount-point, UUID которого сейчас отсутствует среди дисков;
- если такого mount-point нет, но есть только один archive mount-point, предлагает создать второй;
- ищет новый большой диск, который:
  - не является системным;
  - не смонтирован;
  - не имеет разделов;
  - не прописан в `HWMONITOR.json`;
  - больше заданного порога размера;
- если у диска нет UUID, предлагает форматирование в `ext4`;
- записывает новый UUID в `HWMONITOR.json`;
- перезапускает `mnt-hwmonitor.service`;
- пишет понятный лог в `logs/`.

### Запуск

Откройте PowerShell в папке репозитория и выполните:

```powershell
.\scripts\mount-hwmonitor-disk.ps1
```

По умолчанию используется:

- хост: `192.168.1.1`;
- пользователь: `root`;
- конфиг: `/opt/mnt2/configurator/conf/HWMONITOR.json`;
- сервис: `mnt-hwmonitor.service`;
- минимальный размер нового диска: `1000 GB`.

Запуск с другим адресом:

```powershell
.\scripts\mount-hwmonitor-disk.ps1 -HostName 192.168.1.10
```

Запуск с другим порогом размера:

```powershell
.\scripts\mount-hwmonitor-disk.ps1 -MinDiskSizeGb 500
```

Пробный запуск без записи конфига, форматирования и перезапуска сервиса:

```powershell
.\scripts\mount-hwmonitor-disk.ps1 -DryRun
```

### Безопасность

Скрипт не форматирует диск автоматически. Если у выбранного диска нет UUID, он покажет предупреждение и спросит подтверждение:

```text
Форматировать /dev/sdc в ext4? [y/n]
```

Скрипт также отдельно спрашивает подтверждение перед записью нового UUID в конфиг.

Системный диск не выбирается по имени `sdb`. Он определяется через устройство, на котором находится `/`, поэтому переименование дисков после перезагрузки не должно приводить к форматированию системного диска.

### Логи и бэкапы

Файлы создаются локально рядом с репозиторием:

- `logs/mount-hwmonitor-disk-YYYYMMDD-HHMMSS.log`
- `backups/HWMONITOR-YYYYMMDD-HHMMSS.json`

На целевой машине дополнительные бэкапы не создаются.

### Тесты

Тесты не требуют дополнительных модулей PowerShell:

```powershell
.\tests\run-tests.ps1
```

Они проверяют безопасный выбор archive mount-point, создание второго archive-блока и фильтрацию дисков-кандидатов.
